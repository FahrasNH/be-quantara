§10 Catatan Implementasi

  1. Preset vs class config: Bot runtime memuat preset dari legacyStrategies.js. Class strategy mendefinisikan default internal; BotEngine memakai strat.* dari preset.
  2. Partial TP (TM): Aktif bila tpMode: partial. Tutup 50% di 1.5R, sisanya trailing 0.8×ATR.
  3. Fee guards: minEdgeFeeMultiple dan maxEntryExtensionATR mencegah entry edge tipis yang ditelan fee.
  4. Pair override: slMultiplier tier mengalikan lebar SL; positionSizeAdjustment memperkecil ukuran posisi.
